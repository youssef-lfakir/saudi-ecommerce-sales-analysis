# 🛒 Saudi E-Commerce Sales Analytics (2020-2023)

An end-to-end Data Analytics project examining **49,998 transactional records** across Saudi Arabia cities to extract sales performance insights, customer satisfaction metrics, and channel efficiency.

## 📊 Project Components
- **Interactive Power BI Dashboard (`Sales data.pbix`):** Visualizing key metrics (Total Revenue, Orders, Regional Sales, Channel Split).
- **Python Interactive EDA Notebook:** Built with `Pandas` and `Plotly` for data exploration and trend analysis.
- **Dataset:** Transactional logs including Customer Types, Payment Channels, Product Categories, and Sales Reps.

## 🛠 Tools & Tech Stack
- **Power BI:** Data Modeling, Power Query, DAX, Interactive Visuals.
- **Python:** Pandas, Plotly Express.
- **Kaggle:** Published Dataset & Notebook (10/10 Usability Score).
